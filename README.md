# 电商用户价值与运营分析 RFM Project

> 基于 54 万+ 真实跨国电商交易,识别 4,338 名客户价值分布,给出可直接迁移到 Amazon/Shopee 的用户运营策略。

**核心数字**: 4,338 客户 | 65.6% 复购率 | 30.4% 高价值 | 34.7% 流失 | 37 国 | 9-11 月旺季

## 项目概览
- **背景**：电商存量运营时代,精细化用户分层是驱动复购和召回的核心抓手。
- **数据**：UCI Online Retail 公开数据集(541,909 条交易， 4,338 客户，37 国家，2010-12 至 2011-12)。
- **方法**：数据清洗 → RFM 特征工程 → 5 档打分 → 客户分层 → 业务洞察 → 运营策略输出。
- **产出**：Notebook 完整代码 + 8 张可视化图表 + 一页项目说明。

## 关键发现
1. **客户结构待优化**:流失客户占 34.7%，高价值占 30.4%，召回与价值提升空间巨大。
2. **复购基础扎实**:整体复购率 65.6%，远超行业一般水平(30-50%)。
3. **国际市场机会**:英国占 89.1%，德/法/爱等欧洲市场增长潜力待释放。
4. **季节性显著**:9-11 月为销售旺季，11 月峰值 116 万。

## 运营建议(可直接落地)
- 高价值客户(1,319 人):VIP 专属会员体系、个性化推荐、优先发货。
- 忠诚客户(646 人):会员积分、满赠活动、用户调研。
- 流失客户(1,504 人):“老友回归”专属优惠券、限时折扣推送、流失原因调研。
- 国际市场:本地化选品与运营，先聚焦德国/法国/爱尔兰 （Top3）。
