# 电商用户价值与运营分析

## 1. 背景

电商行业从“流量红利”转向“存量运营”，精细化用户运营成为驱动增长的核心引擎。本项目基于 UCI Online Retail 公开数据集（英国一家真实在线零售商，2010-12 至 2011-12），完整跑通“特征工程 → RFM 模型 → 客户分层 → 业务策略”的电商用户分析全链路，为跨境/出海团队的存量用户运营提供可直接复用的方法论与量化结论。


## 2. 方法

1. 数据清洗：删除 CustomerID 缺失、退货单（Quantity < 0）、单价异常（UnitPrice ≤ 0）的记录；统一时间格式

2. 特征工程：计算每个客户的 Recency（最近一次消费距今天数）、Frequency（消费频次）、Monetary（累计消费金额）三个指标

3. RFM 分层：用 qcut 将三个指标各分 4 档，合并打分后将客户分为 5 个层级——高价值客户、忠诚客户、新客户、一般客户、流失客户

4. 业务输出：复购率、客户分层饼图、Top5 高价值客户画像、Top10 国家分布、热销商品、月度销售曲线；为每个层级提出 2-3 条可落地的运营动作


## 3. 核心结论

### 3.1 数据规模

原始 541,909 条交易记录，清洗后有效记录 397,884 条，覆盖 4,338 名客户、37 个国家、12 个月

### 3.2 客户结构

| 客户层级 | 人数 | 占比 |
|:---|:---:|:---:|
| 高价值客户 | 1,319 | 30.4% |
| 忠诚客户 | 646 | 14.9% |
| 新客户 | 665 | 15.3% |
| 一般客户 | 204 | 4.7% |
| 流失客户 | 1,504 | 34.7% |

> 高价值 + 忠诚客户合计 1,965 人（45.3%），构成平台利润核心；流失客户 1,504 人（34.7%），召回空间巨大。

### 3.3 复购表现

整体复购率 **65.6%**，远超行业一般水平（30-50%），平台基础体验和产品力较强。

### 3.4 市场分布

- 英国本土占 **89.1%**
- Top10 国家中德国、法国、爱尔兰等欧洲市场存在增长机会

### 3.5 销售趋势

9-11 月销售持续攀升，11 月达全年峰值 **116 万**；12 月反常回落 55.4%，值得排查。


## 4. 可迁移价值（对跨境/出海电商团队的直接可用性）

1. **方法论零迁移成本**：RFM 模型是 Amazon / Shopee / TikTok Shop 后台最常见的用户分层工具，本项目代码与分层规则稍作改动（打分阈值映射到真实订单）即可直接套用到平台真实数据。

2. **运营动作可平移**：高价值客户专属权益、流失客户定向召回、季节性大促节奏规划，均适用于跨境团队的广告投放、邮件营销、CRM 召回。

3. **国际市场洞察思路**：项目识别出英国之外的潜在机会市场（德/法/爱），该思路可迁移至 Amazon 美/欧/日站点、Shopee 东南亚多市场的本地化选品与运营。

4. **数据能力栈**：完整覆盖 SQL 取数 → Python 清洗 → RFM 建模 → 业务洞察 → 策略建议的链路，对应跨境电商运营助理 / 数据分析专员岗位的日常工作：经营数据监控、用户分层、广告报表与运营策略输出。


*数据来源：UCI Machine Learning Repository - Online Retail Dataset*
