# 数据来源说明

本项目使用的数据来自阿里云

**数据集名称**：UCI Online Retail Dataset - A Gold Standard for Business Analysis
**链接**：https://tianchi.aliyun.com/dataset/218331

**数据说明**：
- 英国一家真实在线零售商的交易数据（2010-12 至 2011-12）
- 原始数据：541,909条交易记录
- 清洗后有效记录：397,884条
- 覆盖客户：4,338人
- 覆盖国家：37个

**字段说明**：
| 字段名 | 含义 |
|:---|:---|
| InvoiceNo | 订单编号 |
| StockCode | 商品编码 |
| Description | 商品描述 |
| Quantity | 数量 |
| InvoiceDate | 交易日期 |
| UnitPrice | 单价 |
| CustomerID | 客户ID |
| Country | 国家 |

**数据已做去重、缺失值处理、退货过滤等清洗操作。**
